# Лабораторная работа №2 — информация об изображениях

**Мацуков Владимир Александрович**  
Java 17 · JavaFX · Maven

Приложение вручную считывает метаданные **JPG, PNG, GIF, TIFF, BMP и PCX**. Библиотеки для получения метаданных не используются.

## Интерфейс

Обычное окно JavaFX без CSS и декоративных элементов:

- кнопки **«Выбрать файлы»**, **«Выбрать папку»**, **«Остановить»**, **«Экспорт CSV»**;
- таблица: имя, формат, размер в пикселях, DPI, глубина цвета, сжатие, статус;
- полоса прогресса и строка с количеством обработанных файлов, ошибок и временем;
- двойной щелчок по строке (или Enter) — подробности и причина ошибки.

Папка обходится с подпапками, до 100 000 файлов. Чтение выполняется в фоновых потоках. Файлы не изменяются и не отправляются в сеть.

## Запуск в IntelliJ IDEA

1. Открыть `pom.xml` как проект.
2. Выбрать **JDK 17** (полный JDK, не JRE).
3. Дождаться загрузки Maven-зависимостей. При первом запуске нужен интернет.
4. Справа открыть **Maven → raster-lab → Plugins → javafx → javafx:run**.

Из PowerShell в папке `lab_2` при установленном JDK 17 (Maven Wrapper включен):

```sh
.\mvnw.cmd javafx:run
```

Для проверки выбрать папку `samples`: 6 корректных файлов и 1 повреждённый PNG.

На Linux/macOS: `sh mvnw javafx:run`.

## Проверки

```sh
.\mvnw.cmd test
```

61 автоматический тест (37 основных и 24 из архива преподавателя): форматы, метаданные, повреждения, TIFF/Exif, CSV, фоновая обработка и отмена. Визуальный запуск на Windows отдельно не проверен.

## Сборка Windows-приложения

На Windows x64 с полным JDK 17 x64 запустить **`build-windows.bat`**.
Результат: **`release/RasterLab/RasterLab.exe`**. Передавать всю папку `RasterLab`, а не один EXE: она содержит Java runtime. Отдельно устанавливать Java на целевой ПК не потребуется.

Готовый Windows EXE в исходниках отсутствует. Скрипт упаковки надо выполнить на Windows; сборка Windows здесь не проверялась.

## Ограничения проверки

Проверяются структура, границы блоков и основные завершающие маркеры. Сжатые пиксели не декодируются; CRC PNG не проверяется. BigTIFF не поддерживается. Поэтому `OK` означает успешную структурную проверку, а не гарантию целостности каждого пикселя. Подробности — в пояснениях.
